# NHANES BIOPRO Dataset for LUNAR

## Overview

This folder contains the NHANES BIOPRO chemistry dataset and derived LUNAR summary workbooks used as the terrestrial reference population for comparison against astronaut and spaceflight analog cohorts within the LUNAR (Longitudinal Unification of Small-N Astronaut Responses) framework.

The NHANES BIOPRO dataset serves as the foundation for all NHANES-referenced z-score calculations, cross-dataset statistical analyses, and Mahalanobis distance calculations performed within LUNAR.

Unlike the original NHANES first pull, which focused on a broad collection of demographic, clinical, dietary, and laboratory variables, the BIOPRO dataset was specifically designed to maximize overlap with the clinical chemistry measurements available in the Inspiration4 astronaut cohort and the UTMB Bed Rest Campaign 1 analog cohort.

NHANES is used as a terrestrial reference population and not as a spaceflight analog.

---

# Purpose

The purpose of the NHANES BIOPRO workflow is to:

1. Create a harmonized clinical chemistry reference population.
2. Identify chemistry biomarkers that overlap with astronaut and bed-rest datasets.
3. Generate population-level descriptive statistics.
4. Provide NHANES means and standard deviations for z-score normalization.
5. Provide a large-scale reference population for Mahalanobis distance calculations.
6. Support cross-cohort comparison within the LUNAR analytical framework.

# How the Combined BIOPRO Dataset Was Created

Workflow:

1. Download NHANES BIOPRO public-use XPT files.
2. Read each file using pandas.
3. Add provenance columns:

   * nhanes_cycle
   * source_file
   * exam_type
4. Harmonize column names.
5. Concatenate all cycles by rows.
6. Preserve SEQN as the participant identifier.
7. Export the final dataset as:

```text
nhanes_biopro_all_cycles_combined.csv
```

Dataset characteristics:

| Metric              |  Value |
| ------------------- | -----: |
| Rows                | 73,170 |
| Unique Participants | 72,624 |
| Duplicate SEQN Rows |    546 |
| Variables           |     91 |

Duplicate SEQN values arise from the 2001–2002 second-exam BIOPRO file and are expected.

# Relationship to the Final LUNAR Analytical Panel

The NHANES overlap framework contains 18 variables.

These variables are used for harmonization and overlap assessment across datasets.

However, the final cross-dataset statistical analyses and multivariate analyses use a locked 17-variable analytical panel.

CRP is not available within NHANES BIOPRO and therefore is excluded from:

* NHANES-referenced z-score analyses
* Cross-dataset statistical comparisons
* Repeated-measures analyses
* Whole-reference Mahalanobis distance calculations
* Bootstrap sensitivity analyses

The final analytical panel contains:

* Albumin
* Albumin/Globulin Ratio
* Alkaline Phosphatase
* ALT
* AST
* Total Bilirubin
* BUN
* BUN/Creatinine Ratio
* Calcium
* Carbon Dioxide

* Globulin
* Glucose
* Potassium
* Total Protein
* Sodium

# Role Within LUNAR

NHANES serves as the terrestrial reference population for all downstream analyses.

NHANES-derived means and standard deviations are used to generate:

```text
z = (x − μNHANES) / σNHANES
```

for astronaut and bed-rest observations.

NHANES also provides the covariance structure used for:

* Whole-reference Mahalanobis distance calculations
* Bootstrap pseudo-reference sensitivity analyses

# Relationship to the Original NHANES First Pull

The original NHANES first pull focused on:

* Demographics
* CBC
* Body measurements
* Blood pressure
* Cotinine
* Lipids
* Diet recalls
* Supplement recalls
* Urine albumin/creatinine

The BIOPRO workflow was developed specifically to provide clinical chemistry measurements with strong overlap to astronaut and bed-rest datasets.

The BIOPRO dataset is therefore the primary NHANES dataset used throughout the LUNAR framework.
